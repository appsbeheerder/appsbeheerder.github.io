About the app

Barcodehammer — read and create barcodes, offline

About Privacy policy Support Terms of use Language: Nederlands · English · Español

Barcodehammer reads and creates barcodes and QR codes. Fully offline: no internet connection, no account and no advertising. What you scan or create stays encrypted on your own device.

What the app does

  • Scan — point the camera at a code and read it.
  • Bulk scanning — read a series of codes one after another; the camera does not stop and the same code adds to its count. The list goes out as an Excel file. (paid version)
  • Create — pick a format, type the content and the app draws the code.
  • History — everything you scan and create, stored encrypted, removable per entry or all at once. Tap an entry and the code is drawn again.
  • Ticket vault — tickets kept apart, behind a lock that opens with your fingerprint, face, PIN or pattern. Without that there is nothing to read. (paid version)
  • Export and share — keep a code as PNG, or send it on to another app. The other way round works too: share an image to Barcodehammer and the app looks for a code in it. (SVG, PDF, high resolution and reading a shared PDF: paid version)
  • Backup — history and tickets in a single file, encrypted with a password you choose yourself.

Which kinds of code

Read and create (13): QR, Data Matrix, Aztec, PDF417, EAN-13, EAN-8, UPC-A, UPC-E, Code 128, Code 39, Code 93, ITF and Codabar.

Create only (7): EAN-2, EAN-5, ISBN, GS1-128, ITF-14, Telepen and RM4SCC.

Which kinds can be read is determined by the operating system's barcode recognition; the app cannot add to that list. For a format you cannot scan back, the app says so before you create it.

Check digits

For EAN-13, EAN-8, UPC-A, UPC-E, ISBN and ITF-14 the app works out the last digit itself if you leave it off, and tells you which digit was added. If you do type it, the app verifies it. Length, permitted characters and capacity are checked before anything is drawn — so you get an explanation instead of a code no scanner can read.

Free and paid

Barcodehammer is a single app. Most of it is simply free; a one-off purchase inside the app adds a few things. No advertising — in neither version — and no subscription.

  • Free: scanning, creating in all twenty formats, the history, the backup, a logo in the middle of a QR code, sharing, keeping a code as PNG, and reading a code from a shared image.
  • Paid version: the ticket vault, bulk scanning with a count and a list as an Excel file, keeping a code as SVG or PDF, a PNG at high resolution (2048 instead of 512 pixels, enough to print on A4), and reading a code from a shared PDF.

For keeping and sharing, the difference is in the quality, never in the kind of code: every format works in both versions. What sits behind the purchase stays visible in the app with a padlock beside it, so you know it is there.

Privacy in one sentence

The app asks for the camera, only to read codes — no photos are taken or stored — and for the biometric permission, only for the lock on the ticket vault. Nothing else, and it never goes online. See the privacy policy.
