# appsbeheerder.github.io

Deze repository bevat geen website meer, alleen omleidingen.

De website van Barcodehammer stond hier een tijd lang in tweevoud: in de
root van deze gebruikerspagina en in de repository `barcodehammer-app`. Twee
kopieen die uit elkaar liepen, met als gevolg dat er een verouderde
privacytekst online stond terwijl de bijgewerkte er al was.

De website hoort thuis op <https://appsbeheerder.github.io/barcodehammer-app/>
en wordt daar gezet door `publiceer-website.ps1` in de app-repository. De
bestanden hier sturen alleen nog door, zodat oudere links blijven werken.

Niets hier met de hand bijwerken.
